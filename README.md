🎓 Student CRUD Application

A simple Java application to manage student records using CRUD operations.

✨ Features

➕ Insert student data
📋 Display student records
✏️ Update student information
🗑️ Delete student records
🗄️ Database connectivity using Java
🛠️ Technologies Used

Java
JDBC
Database (MySQL, if configured)
🎯 Objective

To perform basic student record management using CRUD operations: Create, Read, Update, and Delete.
